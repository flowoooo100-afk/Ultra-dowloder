# Ultra Downloader

A modern Android download manager.

## Project Goals

- Built-in browser
- Download management
- Download progress tracking
- Pause and resume support
- Multiple downloads
- Download history
- File management
- Dark and light themes

## Technology

- HTML
- CSS
- JavaScript
- Capacitor
- Kotlin
- Node.js
- Git

## Development

The application is developed on Android using Termux.

Android APK builds will use GitHub Actions.

## Project Status

Early development - Environment preparation completed.
